# Сценарии проверки Smart City AI

Перед демонстрацией запустите сборщик POI и сервер по `backend/README.md`. Координаты ниже — заданные тестовые точки, а не местоположение конкретного пользователя. Результат зависит от текущих данных OSM; пустой ответ допустим, если подходящих мест нет. Для уверенного демо выберите точку внутри собранного покрытия рядом с POI нужной категории.

## Кофе поблизости

```json
{"latitude":51.09,"longitude":71.42,"query":"Хочу кофе поблизости","duration_minutes":60,"transport":"walking","categories":["cafe"]}
```

Ожидается HTTP 200 и 0–3 кафе из SQLite. Для каждой карточки есть расстояние, время, объяснение и действие. Ни один id не отсутствует в базе. Описание и часы могут быть null. Наличие розетки или тишина не обещаются без данных.

## Короткая прогулка

```json
{"latitude":51.09,"longitude":71.42,"query":"Хочу короткую прогулку","duration_minutes":60,"transport":"walking","categories":["park","attraction","viewpoint"]}
```

Ожидается HTTP 200, разрешённые категории, оценка времени не превышает 60 минут, расстояния неотрицательны. Это альтернативы посещения, а не последовательный маршрут из трёх мест. Проверить также 15 минут: дальние или слишком долгие посещения исключаются.

## Турист либо семья

```json
{"latitude":51.09,"longitude":71.42,"query":"Я турист, хочу посмотреть город","duration_minutes":120,"transport":"walking","categories":["museum","attraction","viewpoint"]}
```

Ожидается HTTP 200, 0–3 подходящих места и конкретные действия. Для семейного варианта задайте query «Я с ребёнком» и categories `["playground","park","museum"]`. Объяснения не должны превращать отсутствие сведений об интерактивах или доступности в подтверждённые факты.

## Отказы и достоверность

| Проверка | Ожидаемое поведение |
| --- | --- |
| latitude 91, время 14, transport driving, пустой query | HTTP 422 и `VALIDATION_ERROR` |
| Пустая база, неизвестная категория либо точка далеко от покрытия | HTTP 200 и `recommendations: []` |
| Нет GEMINI_API_KEY | Реальные POI, шаблонные reason/action, HTTP 200 |
| Gemini timeout, quota error или повреждённый JSON | Шаблонные объяснения и HTTP 200 |
| Gemini вернул неизвестный id | Такой id не попадает в ответ; используются допустимые кандидаты |
| Gemini повторил id | Ответ без дублей и не больше трёх карточек |
| SQLite недоступна | Безопасный HTTP 500, без traceback и пользовательских данных |
| Повторный сбор POI | Количество уникальных OSM type/id не растёт из-за дублей |
| Свежий кеш | Повторная загрузка использует исходную дату данных |
| Overpass недоступен и свежего кеша нет | CLI завершает работу ошибкой, существующие POI остаются |

Автоматические проверки: `python -m pytest -q` из корня проекта. Они используют отдельные временные базы и подменяют внешние API. Настоящую загрузку OSM проверяет CLI; реальный вызов Gemini требует настроенного ключа и не входит в обычный pytest.

## Контрольный запуск 17 октября 2026 года

Overpass вернул 1069 объектов; сохранены 602 именованных POI, 467 записей пропущены. Повторный запуск использовал кеш с исходной датой и сохранил 602 уникальные OSM-пары без дублей. Через настоящий Uvicorn сценарии кофе, прогулки и туриста вернули по три карточки; CORS и HTTP 422 также проверены. Использовались шаблонные объяснения: ключ Gemini не настроен. [Сохранённые ответы](demo-results.json) относятся к тестовой локации и не являются историей пользователя.
