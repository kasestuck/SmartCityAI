## Как проверить локально

Запуск обоих компонентов описан в [README](../README.md). После запуска backend откройте `http://localhost:5173/` через `python tools/serve_frontend.py`. Если порт 8000 занят другим приложением, выберите свободный порт для Uvicorn и согласуйте его с `API_BASE_URL` в `js/config.js`.

Для проверки изменений Git: `git diff origin/main main`; для проверки истории: `git log --graph --oneline --decorate main`. Merge-коммит содержит обе исходные ветки. Удалённая main остаётся без изменений до отдельного разрешения на push.
