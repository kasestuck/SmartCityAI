# 4. Этика и приватность

## Конфиденциальность локации

- **Геолокация — только по нажатию** пользователя и с его согласия; без неё можно выбрать точку на
  карте, ориентир, «центр Астаны» или ввести координаты.
- **«Центр Астаны» подписан явно** как стандартная точка, а не местоположение пользователя.
- **Координаты не сохраняются:** ни в браузере (localStorage, sessionStorage, cookies), ни в логах
  фронта; бекенд не логирует тело запроса, координаты и текст запроса.
- **Минимум данных:** отправляются только поля контракта (точка, запрос, время, категории).
- **В ИИ-модель точные координаты не передаются** — только запрос, бюджет времени и список кандидатов.
- **Сторонним картам** (Google) передаются только координаты места при клике «Маршрут», не пользователя.
- Пользователя предупреждаем: текст запроса может уйти внешнему AI-сервису — не писать личные данные.

## Особые потребности (чувствительные данные)

- Выбор необязательный, подпись: «Отметки нигде не сохраняются».
- Бекенду предлагается не логировать и не хранить это поле; в модель — только как ограничение подбора
  («нужен доступ без ступенек»), без медицинских формулировок.

## Борьба с недостоверной информацией

- **Места только из базы:** ИИ выбирает из найденных кандидатов; выдуманные id отбрасываются.
- **Факты — из базы, не от ИИ:** название, координаты, часы, источник.
- **Без ложных обещаний:** фраз «открыто сейчас», «бесплатно», «есть розетки/Wi-Fi» без данных нет
  (фильтр на бекенде + правила интерфейса).
- **Уровень уверенности:** «по данным OSM, уточняйте перед визитом», «нет данных — уточните на месте».
- **Маркировка источника:** у каждой карточки «Источник: OpenStreetMap», объяснение помечено как
  «Совет AI»; при недоступности ИИ — пометка «по шаблону».
- **Расстояние честно подписано** «по прямой», время — «≈».

## Безопасность пользователей

- Рекомендуем только публичные места из открытой базы (кафе, парки, музеи, площадки).
- Не даём советов, требующих риска (ночью в незнакомом месте и т. п.) — `TODO` правило в промпте.
- Ошибки сервера не раскрывают технических деталей.
- Защита интерфейса: данные с сервера выводятся только как текст (защита от XSS).

## Прозрачность

- В интерфейсе видно, какие данные использованы: точка (и что она не сохраняется), время, категории,
  «пешком», особые потребности.
- Атрибуция «Данные © OpenStreetMap contributors» на страницах и картах.
- Ключ ИИ хранится только на сервере, не попадает в код сайта и репозиторий.

## Ограничения подхода (честно)

- Проверка ответа ИИ ловит явные выдумки, но не любую неточность формулировки.
- Данные OSM неполные и могут устареть; база обновляется сборщиком, дата сбора хранится.
