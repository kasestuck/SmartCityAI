# 3. Тестовые сценарии и ограничения

Как запускать: сайт `http://localhost:5173/` (без `?mock=1`), бекенд с ключом Gemini.
Точку отправления выбирать через «Выбрать точку на карте → ориентир» или «Ввести координаты».
Столбец «Факт» заполняем после прогона (`TODO`): вставить 1–3 названия и короткое «почему»,
приложить скриншот в `docs/submission/screens/`.

Общие ожидания для любого ответа (из кейса): **1–3 конкретных места**, у каждого — короткое «почему»,
примерное время на посещение и «что делать там». Никакого «открыто сейчас» без данных.

## Ограничения (честно)

1. **Данные.** OSM: у большинства мест нет описания; рейтинга и популярности нет; часы работы и
   доступность заполнены у малой части мест (тег `wheelchair` — единицы в районе ЭКСПО).
2. **Расстояние по прямой**, а не пеший маршрут; время — приблизительный бюджет.
3. **Только пешком** в MVP.
4. **Нет событий** (выставки, концерты) — их нет в базе, ИИ их не обещает.
5. **«Открыто сейчас» не определяем** — нет надёжных данных; показываем часы как есть.
6. **ИИ может ошибаться в формулировках** — проверка ловит явные выдумки (id, «открыто», «бесплатно»),
   но не любое неточное слово.
7. **Внешние сервисы:** погода (Open-Meteo) и новости (GDELT) могут быть недоступны — интерфейс это переживает.
8. **Город один** — только Астана.
