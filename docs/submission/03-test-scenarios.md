# 3. Тестовые сценарии и ограничения

Как запускать: сайт `http://localhost:5173/` (без `?mock=1`), бекенд с ключом Gemini.
Точку отправления выбирать через «Выбрать точку на карте → ориентир» или «Ввести координаты».
Столбец «Факт» для сквозных сценариев заполняем после прогона (`TODO`): вставить названия и короткое «почему»,
приложить скриншот в `docs/submission/screens/`.

Общие ожидания для непустого ответа: **1–3 конкретных места** (или одно с предупреждением о превышении бюджета), у каждого — короткое «почему»,
примерное время на посещение и «что делать там». Никакого «открыто сейчас» без данных.

### S9. Ошибки и сбои (проверено на фронте)
| Ситуация | Что видит пользователь |
|---|---|
| Сервер не отвечает / нет сети | «Нет связи с сервером» + «Повторить» |
| Таймаут 15 с | «Сервер не ответил за 15 секунд» |
| 429 | «Слишком много запросов, подождите минуту», кнопка заблокирована на 60 с с отсчётом |
| 500 | «Что-то пошло не так, попробуйте позже» + «Повторить» |
| Gemini недоступна, HTTP 200 | реальные места; `generated_by: "fallback_template"` и пометка о шаблоне |
| 503 с местами (mock зарезервированного ответа) | места + «AI-объяснения недоступны — по шаблону» |
| 422 | подсветка поля и сообщение |
| Отказ в геолокации | предложение выбрать точку на карте / центр / координаты |

## Ограничения (честно)

1. **Данные.** OSM: у большинства мест нет описания; рейтинга и популярности нет; часы работы и
   доступность заполнены у малой части мест (тег `wheelchair` — единицы в районе ЭКСПО).
2. **Расстояние по прямой**, а не пеший маршрут; время — приблизительный бюджет.
3. **Только пешком** в MVP.
4. **Нет событий** (выставки, концерты) — их нет в базе, ИИ их не обещает.
5. **Статус только по расписанию OSM:** `is_open_now` рассчитан библиотекой; неизвестные и неподдерживаемые часы дают `null`. Фактическая работа не проверена, закрытые места не исключаются.
6. **ИИ может ошибаться в формулировках** — проверка ловит явные выдумки (id, «открыто», «бесплатно»),
   но не любое неточное слово.
7. **Внешние сервисы:** Google Maps/Fonts, cdnjs, тайлы OSM, Open-Meteo и GDELT могут быть недоступны. Запросы тайлов могут раскрывать область выбранной точки; подробности — в [privacy-заметках](../ethics-and-privacy.md).
8. **Город один** — только Астана.
