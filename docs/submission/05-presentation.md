## Цифры для слайдов

- **602** реальных места Астаны, 7 категорий, сбор автоматизирован (OpenStreetMap → SQLite).
- **0–3** рекомендации; живой казахский ответ с тремя местами получен за **6,6 с** 18.10.2026 (`live_check_language_kk` в [demo-results.json](../demo-results.json)). Это один замер API, не SLA; время сквозного демо ещё измерить.
- **0** сохранённых координат пользователя.
- **3** языка интерфейса: русский, казахский, английский; **2** языка API: русский и казахский. В EN ответ русский с пометкой.
- **8** быстрых сценариев в один клик.

## Риски → меры (для слайда 9)

| Риск | Мера |
|---|---|
| ИИ недоступен или исчерпан лимит | Реальные места с шаблонным объяснением, HTTP 200, пометка в интерфейсе |
| ИИ сформулировал неточно | Факты из базы; фильтр «открыто/бесплатно/Wi-Fi»; id только из кандидатов |
| Неполные данные (часы, доступность) | Честные «нет данных» / «уточните»; обогащение из Wikipedia (план) |
| Передача локации | Не храним историю и не передаём точные координаты отдельными полями в модель; раскрываем внешние карты и область тайлов в privacy-заметках |
| Пустая выдача | Совет изменить время/категорию; не выдумываем места |
