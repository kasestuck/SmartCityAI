# SmartCityAI — ASTANA GO AI

Сайт для туристов и жителей Астаны: пользователь пишет, чего хочется, указывает точку отправления и время,
а бекенд возвращает до трёх реальных мест рядом с объяснением. Фронт сам места не придумывает —
места подборки приходят с API (`docs/api-contract.md`).

Фронтенд: чистые HTML/CSS/JS (ES2020), без сборщиков и npm; макет — Figma «СмартИИ».
Бэкенд: FastAPI, SQLite, сбор POI Астаны из OpenStreetMap, геопоиск и Gemini RAG с шаблонным fallback.
API возвращает от нуля до трёх реальных мест. Ключ Gemini необязателен.

## Как открыть

Нужен Python 3.11 или новее. Команды выполняются из корня репозитория.
Для первого запуска бэкенда в Windows PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-dev.txt
if (-not (Test-Path -LiteralPath backend/.env)) { Copy-Item backend/.env.example backend/.env }
.\.venv\Scripts\python.exe -m backend.scripts.collect_poi
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --no-access-log
```

Существующий `backend/.env` сохраняется. Для Gemini задайте ключ только в серверном окружении
или этом локальном файле. Подробности и команды Linux/macOS — в [backend/README.md](backend/README.md).

В другом терминале запустите сервер публичных файлов фронтенда:

```bash
python tools/serve_frontend.py
```

Он слушает `127.0.0.1:5173` и отдаёт только публичные файлы сайта; `backend/.env`, база и исходники
бэкенда недоступны. Бэкенд по умолчанию разрешает CORS для `http://localhost:5173`.

Затем открыть <http://localhost:5173/>. Без бекенда — <http://localhost:5173/?mock=1>.

Если после правок CSS/JS браузер показывает старую версию — это кеш. Нажмите Ctrl+F5 или поднимите
версию `?v=…` в ссылках на `css/` и `js/` в `index.html` и `styleguide.html`.

`index.html` открывается и напрямую из файла (`file://`), но тогда работает только mock-режим:
запросы к бекенду с origin `null` заблокирует CORS.

## Настройка `API_BASE_URL`

Адрес бекенда задаётся в одном месте — `js/config.js`:

```js
const API_BASE_URL = "http://localhost:8000";
```

Там же таймауты (запрос 15 с, health 5 с), пауза после 429 (60 с), список длительностей и категорий.
Секретов во фронте нет: ключ Gemini хранится только на бекенде.

## Mock-режим

Mock-ответы лежат в `js/mock-data.js`; примеры кофе, прогулки и туриста основаны на настоящих
ответах из `docs/demo-results.json`. Mock демонстрирует состояния интерфейса и не подтверждает живой вызов Gemini.
Mock подменяет `fetch`, поэтому проходит тот же код разбора ответов и ошибок, что и для живого API.

Включить:
- в `js/config.js`: `const USE_MOCK = true;`
- или без правки файла — параметром в адресе:

| Адрес | Что вернёт mock |
|---|---|
| `?mock=1` | 200, места подбираются по категориям/тексту запроса |
| `?mock=empty` | 200, `{"recommendations": []}` |
| `?mock=422` | 422 `VALIDATION_ERROR` |
| `?mock=429` | 429 `RATE_LIMITED` (кнопка блокируется на 60 с) |
| `?mock=500` | 500 `INTERNAL_ERROR` |
| `?mock=503` | 503, но с местами (шаблонные объяснения) |
| `?mock=503-empty` | 503 `AI_UNAVAILABLE` без данных |
| `?mock=html` | 502 с HTML от «прокси» (не формат контракта) |
| `?mock=network` | обрыв сети |
| `?mock=timeout` | сервер молчит → таймаут 15 с |
| `?mock=0` | выключить mock, даже если `USE_MOCK = true` |

Адрес API через URL не переопределяется — чтобы ссылка не могла отправить запрос и координаты на чужой сервер.

## Демо-сценарии (раздел 6 ТЗ)

На главной блок «Быстрые идеи» — каждый сценарий запускается одной кнопкой
(после выбора точки отправления):

1. **Короткая прогулка** — «Хочу короткую прогулку», 30 мин, `["park"]`
2. **Кофе рядом** — «Кофе рядом», 15 мин, `["cafe"]`
3. **С семьёй** — «Куда сходить с семьёй», 120 мин, `["park", "playground", "museum"]`

Плюс «Культура», «Что-то необычное», «Поужинать», «С детьми на площадку» и «Вечерняя прогулка».
В mock-режиме для ресторанов данных нет — «Поужинать» покажет состояние «ничего не найдено»; на реальном бекенде рестораны есть.

Для презентации и скриншотов: `?demo=walk|coffee|family|culture|views|dinner|kids|evening` сразу запускает сценарий от явно подписанной
точки «Центр Астаны». Пример: <http://localhost:5173/?mock=1&demo=family#/map>.

## Языки и доступная среда

- Интерфейс на **русском, казахском и английском**: переключатель RU / KZ / EN в шапке.
  Язык запоминается в браузере; открыть сразу нужный: `?lang=kk` или `?lang=en`. Тексты — в `js/i18n.js`.
- API поддерживает `language: "ru"` и `"kk"`: пояснения, действия и системные примечания приходят
  на выбранном языке. В английском интерфейсе отправляется `ru` и показывается явная пометка о русском ответе.
  Названия и описания мест сохраняют язык OSM. `BACKEND_SUPPORTS_LANGUAGE = true`.
- Карточки показывают доступность по исходному тегу OSM `wheelchair` (в API также `accessibility`).
  Отсутствие тега означает «нет данных — уточните на месте»; это не проверка маршрута или входа.
- Фильтры **особых потребностей** (`wheelchair`, `low_mobility`, `quiet`) остаются предложением:
  `BACKEND_SUPPORTS_ACCESSIBILITY = false`, поле запроса не отправляется в живой API.
  Их поведение можно посмотреть в mock-режиме; поддержка английского ответа и `GET /api/poi` также
  описана как план в [предложении к контракту](docs/proposal-accessibility-language.md).

## Экраны

| Адрес | Экран |
|---|---|
| `#/` | Главная: короткий запрос, быстрые идеи, фото + погода + новости Астаны, Google-карта, «Три шага» |
| `#/guide` | AI-гид: полная форма (точка, время, категории) слева, подборка справа, карта мест |
| `#/map`, `#/map/<id>` | Карта: подборка крупными метками + слой всех мест города; вкладки «Вся карта» (602 места) и «Вокруг» (радиус 1,5 км от точки отправления); выбор метки ↔ список справа |
| `#/place/<id>` | Детальная страница места (как «Ботанический сад» в макете) — только из результатов поиска, без отдельного запроса |
| `styleguide.html` | Компоненты и состояния интерфейса |

Результаты поиска и выбранная точка живут в памяти вкладки и не сохраняются. После перезагрузки
подборку нужно получить заново; общий слой мест остаётся доступен из публичного снимка OSM.

Экран «Карта» — Leaflet + тайлы OpenStreetMap (`js/placesmap.js`): все места подборки одновременно,
клик по метке выделяет место в списке и наоборот. В диалоге выбора точки также используется Leaflet 1.9.4
с cdnjs (с проверкой целостности SRI) и тайлы OSM. Библиотека загружается при первом открытии этих карт.
Запросы тайлов показывают провайдеру область просмотра, которая может быть рядом с выбранной точкой пользователя.

Карты на главной, в AI-гиде и на странице места — Google Maps без ключа API (iframe).
Они получают название города или координаты POI. «Маршрут» открывает Google Карты с координатами
места назначения; точку старта Google определяет сам. Приложение не добавляет координаты пользователя
в URL Google, но обращения к внешним картам передают провайдеру обычные сетевые данные браузера.

## Погода и новости на главной

- **Погода** — [Open-Meteo](https://open-meteo.com/), без ключа, для фиксированной точки «Астана».
- **Новости** — [GDELT](https://www.gdeltproject.org/), без ключа: свежие публикации казахстанских СМИ
  с упоминанием Астаны за 3 дня. GDELT медленный (10–15 с на ответ) и пускает не чаще 1 запроса в 5 с;
  сверх лимита отвечает 429 без CORS-заголовка, и браузер видит это как сетевую ошибку. Поэтому:
  до 3 попыток с паузой 6 с; карточки новостей (заголовки, ссылки и служебные сведения) кешируются в `localStorage` — свежими считаются
  20 минут, при сбое показываются сохранённые до 24 часов с пометкой; если нет ничего — ссылки
  на Kazinform, Tengrinews и Astana TV.

Запросы погоды и новостей используют фиксированную Астану, без текста пожелания и координат пользователя.
Кроме них браузер обращается к Google Fonts, Google Maps, cdnjs и тайлам OSM. Внешние провайдеры получают
сетевые данные соединения. Проксирование погоды и новостей через `/api/weather` и `/api/news` пока лишь предложение.

```
tools/serve_frontend.py      # локальный сервер только публичных файлов фронтенда
backend/                    # FastAPI, SQLite, сбор POI, геопоиск, Gemini и тесты

js/styleguide.js      # витрина компонентов
assets/               # иконки и фото из Figma

docs/proposal-accessibility-language.md  # предложение: особые потребности и язык ответа
```

## Адаптив

Breakpoints 768 и 1024 px. В Figma есть мобильные макеты 320/390 и планшетный 768 — сделано по ним:
на мобильных снизу закреплённая навигация, колонки складываются в одну.
Проверено на 375, 768, 1024, 1440 px — без горизонтальной прокрутки.

## Как проверить

1. **Сценарии на mock:** `?mock=1`, выбрать «Центр Астаны», нажать каждую быструю идею.
2. **Сценарии на бекенде:** запустить бекенд (см. [backend/README.md](backend/README.md)), открыть `http://localhost:5173/`.
3. **Ошибки:** пройти все `?mock=…` из таблицы выше.
4. **Геолокация:** «Использовать моё местоположение» → отказать в доступе → появится подсказка выбрать точку
   на карте, центр Астаны или ввести координаты. Геолокация запрашивается только по нажатию.
5. **Null-поля:** в выдаче нет «undefined»/«null»; блок часов работы показывается только если `opening_hours` не `null`.
6. **Повторная отправка:** выдача заменяется, не дублируется; во время запроса кнопка заблокирована.
7. **Адаптив:** 375, 768, 1024, 1440 px.
8. **Метаданные API:** проверьте `budget_warning`, статус по расписанию (`is_open_now`, `status_note`),
   происхождение пояснения (`generated_by`) и применённые параметры (`query_context`). Шаблонный ответ
   может иметь HTTP 200 и должен быть подписан по значению `generated_by`.
9. **Языки:** RU отправляет `ru`, KZ — `kk`, EN — `ru` с пометкой; `accessibility` в живом запросе отсутствует.

## Приватность и безопасность

- Координаты и текст запроса не пишутся в `localStorage`/`sessionStorage`/cookies и не логируются в консоль.
- Отправляются только поля контракта; `categories` не отправляется, если ничего не выбрано.
- Данные сервера выводятся только через `textContent`; технические детали ошибок пользователю не показываются.
- В `localStorage` сохраняются выбор языка и кеш новостей, без истории координат и запросов.
- Внешние ресурсы: Google Fonts, Google Maps (iframe), Leaflet с cdnjs и тайлы OSM (выбор точки и экран карты), Open-Meteo, GDELT. Собственная аналитика не подключена.
- Геолокация запрашивается по нажатию через разрешение браузера. В форме есть пояснение о координатах и предупреждение о передаче текста AI-сервису; отдельная страница приватности и полный экран согласия пока запланированы.
- Атрибуция «Данные © OpenStreetMap contributors» — в подвале, на карте и в подписи к выдаче.
