# SmartCityAI — фронтенд (ASTANA GO AI)

Сайт для туристов и жителей Астаны: пользователь пишет, чего хочется, указывает точку отправления и время,
а бекенд возвращает до трёх реальных мест рядом с объяснением. Фронт сам места не придумывает —
все данные приходят с API (`docs/api-contract.md`).

Чистые HTML/CSS/JS (ES2020), без сборщиков и npm. Макет — Figma «СмартИИ».

## Как открыть

Нужен любой статический сервер. Бекенд по умолчанию разрешает CORS для `http://localhost:5173`,
поэтому удобнее всего так (из корня репозитория):

```bash
python -m http.server 5173 --bind 127.0.0.1
```

Затем открыть <http://localhost:5173/>. Без бекенда — <http://localhost:5173/?mock=1>.

`index.html` открывается и напрямую из файла (`file://`), но тогда работает только mock-режим:
запросы к бекенду с origin `null` заблокирует CORS.

## Настройка `API_BASE_URL`

Адрес бекенда задаётся в одном месте — `js/config.js`:

```js
const API_BASE_URL = "http://localhost:8000";
```

Там же таймауты (запрос 15 с, health 5 с), пауза после 429 (60 с), список длительностей и категорий.
Секретов во фронте нет: ключ Gemini хранится только на бекенде.

## Mock-режим

Mock-ответы лежат в `js/mock-data.js` — в точности по контракту
(кофе / прогулка / турист — копии настоящих ответов бекенда из `docs/demo-results.json`).
Mock подменяет `fetch`, поэтому проходит тот же код разбора ответов и ошибок, что и для живого API.

Включить:
- в `js/config.js`: `const USE_MOCK = true;`
- или без правки файла — параметром в адресе:

| Адрес | Что вернёт mock |
|---|---|
| `?mock=1` | 200, места подбираются по категориям/тексту запроса |
| `?mock=empty` | 200, `{"recommendations": []}` |
| `?mock=422` | 422 `VALIDATION_ERROR` |
| `?mock=429` | 429 `RATE_LIMITED` (кнопка блокируется на 60 с) |
| `?mock=500` | 500 `INTERNAL_ERROR` |
| `?mock=503` | 503, но с местами (шаблонные объяснения) |
| `?mock=503-empty` | 503 `AI_UNAVAILABLE` без данных |
| `?mock=html` | 502 с HTML от «прокси» (не формат контракта) |
| `?mock=network` | обрыв сети |
| `?mock=timeout` | сервер молчит → таймаут 15 с |
| `?mock=0` | выключить mock, даже если `USE_MOCK = true` |

Адрес API через URL не переопределяется — чтобы ссылка не могла отправить запрос и координаты на чужой сервер.

## Демо-сценарии (раздел 6 ТЗ)

На главной блок «Быстрые идеи» — каждый сценарий запускается одной кнопкой
(после выбора точки отправления):

1. **🌿 Короткая прогулка** — «Хочу короткую прогулку», 30 мин, `["park"]`
2. **☕ Кофе рядом** — «Кофе рядом», 15 мин, `["cafe"]`
3. **👨‍👩‍👧 С семьёй** — «Куда сходить с семьёй», 120 мин, `["park", "playground", "museum"]`

Плюс «🎨 Культура» и «✨ Что-то необычное» из макета.

Для презентации и скриншотов: `?demo=walk|coffee|family|culture|views` сразу запускает сценарий от явно подписанной
точки «Центр Астаны». Пример: <http://localhost:5173/?mock=1&demo=family#/map>.

## Экраны

| Адрес | Экран |
|---|---|
| `#/` | Главная: форма, быстрые идеи, блок «Твоя подборка», «Исследуй Астану», «Три шага» |
| `#/guide` | Главная с прокруткой к подборке (пункт меню «AI-гид») |
| `#/map`, `#/map/<id>` | Карта: схема с маркерами, выбранное место подсвечено |
| `#/place/<id>` | Детальная страница места (как «Ботанический сад» в макете) — только из результатов поиска, без отдельного запроса |
| `styleguide.html` | Компоненты и состояния интерфейса |

Результаты живут в памяти вкладки и не сохраняются. После перезагрузки карта и детальная страница
покажут пустое состояние с предложением найти места заново — это сделано намеренно (приватность).

Карта — собственная SVG-схема без Leaflet и тайлов: река, ориентиры и маркеры ставятся по координатам,
фон кварталов декоративный. «Маршрут» открывает OpenStreetMap, куда передаются только координаты места
(точку старта пользователь вводит сам).

## Структура

```
index.html            # Главная + экраны «Карта» и «Место» (hash-роутинг)
styleguide.html       # Компоненты и состояния
css/variables.css     # цвета, шрифты, отступы из Figma
css/base.css          # сброс, типографика
css/components.css    # кнопки, поля, чипсы, карточки, шапка, подвал, состояния, карта
js/config.js          # API_BASE_URL и константы
js/api.js             # запросы к бекенду и разбор ошибок
js/mock-data.js       # mock-ответы по контракту
js/render.js          # построение DOM (только textContent)
js/map.js             # схематичная карта на SVG
js/main.js            # форма, геолокация, вывод результатов, роутинг
js/styleguide.js      # витрина компонентов
assets/               # иконки и фото из Figma
docs/api-contract.md  # общий контракт с бекендом (не менять без него)
```

## Адаптив

Breakpoints 768 и 1024 px. В Figma есть мобильные макеты 320/390 и планшетный 768 — сделано по ним:
на мобильных снизу закреплённая навигация, колонки складываются в одну.
Проверено на 375, 768, 1024, 1440 px — без горизонтальной прокрутки.

## Как проверить

1. **Сценарии на mock:** `?mock=1`, выбрать «Центр Астаны», нажать каждую быструю идею.
2. **Сценарии на бекенде:** запустить бекенд (см. `backend/README.md` в ветке `BACK`), открыть `http://localhost:5173/`.
3. **Ошибки:** пройти все `?mock=…` из таблицы выше.
4. **Геолокация:** «Использовать моё местоположение» → отказать в доступе → появится подсказка выбрать точку
   на карте, центр Астаны или ввести координаты. Геолокация запрашивается только по нажатию.
5. **Null-поля:** в выдаче нет «undefined»/«null»; блок часов работы показывается только если `opening_hours` не `null`.
6. **Повторная отправка:** выдача заменяется, не дублируется; во время запроса кнопка заблокирована.
7. **Адаптив:** 375, 768, 1024, 1440 px.

## Приватность и безопасность

- Координаты и текст запроса не пишутся в `localStorage`/`sessionStorage`/cookies и не логируются в консоль.
- Отправляются только поля контракта; `categories` не отправляется, если ничего не выбрано.
- Данные сервера выводятся только через `textContent`; технические детали ошибок пользователю не показываются.
- Внешние ресурсы: только Google Fonts. Трекеров нет.
- Атрибуция «Данные © OpenStreetMap contributors» — в подвале, на карте и в подписи к выдаче.
